# 圖表誠實與可讀細則：選圖、逐圖種紅線、對比與灰階

`figure_style.md` 管版面規格（尺寸、字級、despine）；本檔管「這張圖會不會讓讀者讀錯」。
SKILL.md 的總紅線（不截斷 y 軸、不藏信賴帶、不放大不顯著效果）在這裡展開成逐圖種規則。
出圖前讀一次，交付前對末節自檢。

## 一、選圖：讀者必須看懂什麼

| 讀者必須看懂… | 圖種 | 函式 |
|---|---|---|
| 主迴歸各係數的方向與信賴區間 | 係數森林圖 | `coefficient_forest_plot` |
| 非線性（倒U／U）與轉折點 | 轉折點圖 | `quadratic_turning_point_plot` |
| 斜率在不同調節值下是否翻轉 | 交互作用／邊際效果圖 | `interaction_plot` |
| 處理前後的動態效果 | 事件研究圖 | `event_study_plot` |
| 事件日前後的累積異常報酬 | CAR 曲線 | `car_plot` |
| 兩組的平均差異 | 分組比較 | `group_comparison_plot` |
| 多組逐年走勢 | 趨勢圖 | `trend_plot` |
| 同一批類別在**兩個**時點（或兩組）間的差距 | 啞鈴圖（類別 4–8） | 無，matplotlib 手寫（三-6） |
| 多個系列在兩時點間的升降與名次交叉 | 斜率圖（系列 4–10） | 無，手寫（三-7） |
| 兩個類別軸交叉的數值型態 | 熱圖 | 無，手寫（三-8） |

**三道門**（成立就不畫圖）：
- 只有 2–3 個數字 → 寫成一句話。
- 讀者要的是**精確數值**而不是**型態** → 用表。相關係數矩陣在商管期刊慣例是表（敘述統計
  與相關係數表），熱圖只放口試簡報或附錄。
- 整張迴歸表 → 留在表；圖只挑假說相關的係數。

## 二、全圖種共通

1. **焦點是編輯決定，不是最大值。** 一張圖一個焦點（系列或係數），給「圖說要講的那一個」，
   不是自動給係數最大、最顯著的那個；其他一律中性。焦點再用**線寬或標記形狀**加強一次，
   不只靠色相。
2. **所有估計都畫。** 刪掉不顯著的係數或不利的組別，等於換了讀者看到的母體；真要刪，
   圖註寫明刪了什麼、為什麼。
3. **排序要說。** 森林圖、啞鈴圖的列序依什麼排（模型順序／係數大小／變化量——有號還是
   絕對值），寫在圖註；沒交代的排序會被讀成隨意。
4. **範圍要說。** 軸不從 0 起的圖（斜率圖、轉折點圖）在圖註寫出軸的範圍；窄範圍會等比
   放大所有差異。
5. **系列 ≤5 時直接標名**（線尾寫系列名），讀者不必來回對照圖例；用圖例時只列實際出現的系列。

## 三、逐圖種紅線

1. **係數森林圖**：零線必畫；誤差棒是 95% CI 還是 ±SE，寫在軸標或圖註。顯著與不顯著靠
   **實心 vs 空心**標記區分，不只靠藍 vs 灰——灰階下顏色差異會消失（見第四節）；不顯著者的
   線與空心點外框用對比 ≥3:1 的灰（`#808080` 以上）。`coefficient_forest_plot` 已內建
   （2026-10-08）：不顯著者為空心點、灰 `#767676`（4.54:1），原 `#9a9a93`（2.83:1）已汰除。
2. **交互作用／簡單斜率**：調節值取法寫明（平均 ±1 SD，或第 10／90 百分位）；x 軸只畫樣本
   實際範圍，不外推；每條線**顏色＋線型**雙重編碼——`interaction_plot` 已內建線型循環
   （2026-10-08）；線多或圖例離線太遠時，改在線尾直接標調節值。
3. **轉折點圖**：β₂ 顯著性、x* 是否落在樣本範圍等規則見 SKILL.md，不重複。
4. **分組比較長條**：y 軸一律從 0 起（長條以長度編碼，截斷就是誇大）；誤差線是 SE、SD 還是
   95% CI 寫進圖註。要比的是兩時點差距時改用啞鈴圖，不要並排兩根長條。
5. **趨勢圖**：用折線不用平滑曲線（平滑會畫出沒觀測過的值）；缺年份要斷線，不可連過去；
   超過 5 條線就拆圖。`trend_plot` 已內建線型＋標記雙重第二線索（2026-10-08）；只想凸顯
   焦點系列時，用回傳的 `ax` 拿掉其他系列的標記。
6. **啞鈴圖**（兩時點／兩組差距）：水平擺放，兩端共用一軸、同一單位；兩端都標數值；兩點以
   **空心 vs 實心**區分，灰階與色弱都看得出；連線代表**差距不是軌跡**，不可敘述成「逐年上升」；
   缺一端的類別要揭露，不補值、不默默刪；軸不可截到資料的最小最大值（截了，每段差距都被放大）。
7. **斜率圖**：左右兩軸同尺度、同單位（單位不同的兩變數改散佈圖）；兩端都標名稱與數值；
   系列 4–10 條；不畫格線（兩端數值已印出）。
8. **熱圖**：無號數值（次數、比率）用單一色相深淺；有正負且 0 有意義（相關係數）才用雙色
   發散，0 對應中性色；每格印數值；列與欄完整列出，排除的寫在圖註。

## 四、對比與灰階（2026-10-08 依 WCAG 2.1 相對亮度公式實算）

色盲友善不等於對比足夠。WCAG 2.1 的門檻：圖中資料線、點等**非文字圖形 ≥3:1**（SC 1.4.11），
一般文字 ≥4.5:1、大字 ≥3:1（SC 1.4.3）。Okabe-Ito 各色在白底：

| 色 | 色碼 | 白底對比 | 灰階明度 L* | 細線／資料點 | 文字 |
|---|---|---|---|---|---|
| 藍 | #0072B2 | 5.19:1 | 46 | ✓ | ✓ |
| 橘紅 | #D55E00 | 3.87:1 | 54 | ✓ | 僅大字 |
| 綠 | #009E73 | 3.42:1 | 58 | ✓ | 僅大字 |
| 粉 | #CC79A7 | 3.06:1 | 61 | 勉強 | ✗ |
| 灰 | #999999 | 2.85:1 | 63 | ✗（改 #808080，3.95:1） | ✗ |
| 淺藍 | #56B4E9 | 2.31:1 | 70 | ✗（只作填色或加深色外框） | ✗ |
| 黃 | #E69F00 | 2.25:1 | 71 | ✗（同上） | ✗ |

- **灰階幾乎不分色**：七色轉灰階後明度全擠在 46–71；最難分的三對是黃≈淺藍（差 0.8）、
  粉≈灰（差 2.2）、橘紅≈綠（差 3.6）。所以黑白印刷時，**系列 ≥2 就必須加線型或標記形狀**，
  不能只靠 `PALETTE` 的顏色順序。
- **邊框扛對比，填色扛辨識**：淺色（黃、淺藍）只能大面積填色；要當資料點時加深色外框，
  讓外框達到 3:1。

## 五、交付前自檢

- [ ] 過了三道門（不是一句話或一張表就能說完的）
- [ ] 焦點只有一個，且是圖說要講的那個；焦點有線寬或形狀加強
- [ ] 所有估計都畫了；刪了什麼、排序依據、軸範圍都寫進圖註
- [ ] 長條 y 軸從 0 起；趨勢不平滑、缺年份斷線
- [ ] 系列 ≥2 時有線型或標記形狀備援；不顯著者靠空心標記區分
- [ ] 細線、資料點對比 ≥3:1；文字 ≥4.5:1（黃、淺藍、#999999 沒拿來畫細線或寫字）
