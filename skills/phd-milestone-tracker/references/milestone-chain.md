# 關卡相依鏈：修課 → 資格考 → 著作審查 → 候選人資格 → 前三章口試 → 論文口試

> 對應 SKILL.md 階段三「相依關係與下一步」。本檔把 `<reference_rules>` 裡
> 各關卡的先後邏輯，攤開成一張可查閱的相依鏈說明＋常見卡點清單。**所有時間
> 長度與門檻數字沿用 SKILL.md 的基準值，一律以系辦最新版簡章為準**；本檔
> 不新增任何 SKILL.md 未列出的具體數字，只補「為什麼卡在這裡、卡了會怎樣」
> 的邏輯說明。

## 一、相依鏈總覽（前一關未完成，後一關無法申請）

```
[修課(學分)] ──┬──────────────────────────────────────────┐
               │                                            │
               ▼                                            │
        [學科資格考(校外，主科+研方)]                        │
               │  通過後 1 個月內                             │
               ▼                                            │
        [申請指導教授]                                       │
               │                                            │
               ├────────────────◄───────────────────────────┘
               │  (修課與找指導教授可並行，但都是後續關卡的前提)
               ▼
        [學術著作審查]（每學期初召開，發表分流門檻依畢業年資而定）
               │  通過才能申請下一關
               ▼
        [博士候選人資格考核會]（論文初稿、前三章口試）
               │  口試前三週繳申請書
               ▼
        [博士生論文研討]（校外公開發表）
               │  發表前三週申請、前三天交 PPT
               ▼
        [博士論文口試]（校內）
               │  口試前一個月申請；須先通過學術著作審查
               ▼

```

## 二、逐關依賴邏輯與常見卡點

### 關卡 1｜修課（學分）

- **依賴什麼**：無前置關卡，入學即可開始修課。
- **餵給誰**：學分修畢是博士候選人資格考核會與畢業的前提條件之一，但**不是**
  學科資格考的前提——資格考可以在學分修畢前就先考(甚至鼓勵盡早考，因為
  資格考有退學紅線)。
- **常見卡點**：
  - 誤以為要修完所有學分才能考資格考，因而延後應考時間，擠壓到退學紅線
    前的緩衝——這是最常見的誤解，SKILL.md 的核心設計就是要提早破解它。
  - 在職生因工作排擠選課時間，導致主修/副修/研究方法各領域學分修課進度
    不均衡，某一領域學分long期落後。

### 關卡 2｜學科資格考（校外，主科＋研方）

- **依賴什麼**：無強制前置關卡(可與修課並行)，但實務上通常會先修完對應
  考科的核心課程再應考，準備上較有效率。
- **餵給誰**：通過是「申請指導教授」的直接前提(限定窗口期，見關卡3)；
  也是避免退學紅線的關鍵——這是全鏈中**唯一附帶退學後果**的關卡，SKILL.md
  要求永遠把這條紅線放在輸出最顯眼處。
- **常見卡點**：
  - 資格考通常一年只有固定考試機會(如期末後一次)，若某次沒通過，下次
    機會可能要等到下學期，容易在計算「還剩幾次機會」時算錯，誤判時間
    餘裕。
  - 主科與研方是否需要同一次全數通過、或可分次通過各自保留成績，這點
    細節在不同屆別/簡章版本可能不同，**務必向系辦確認、不自行假設**。

### 關卡 3｜申請指導教授

- **依賴什麼**：學科資格考(主科＋研方)全數通過，且**有申請窗口限制**
  (通過後一段期限內須繳交申請書)——這是全鏈中窗口最短、最容易被忽略的
  一關，因為前一關(資格考)剛通過的心理狀態通常是「鬆一口氣」而非「馬上
  行動」。
- **餵給誰**：確定指導教授後，才能正式展開論文方向的指導關係，間接影響
  後續「學術著作審查」要投稿的方向是否有指導教授背書。
- **常見卡點**：
  - 資格考通過後忙於工作或其他事務，錯過申請指導教授的窗口期，需額外
    向系辦確認補救方式。
  - 選定指導教授的過程若牽涉指導教授員額限制、雙方意願確認，實務上建議
    在資格考應考前就已非正式接觸過potential指導教授，通過後才不會臨時
    找不到人。

### 關卡 4｜學術著作審查

- **依賴什麼**：無明確法規前置關卡，但實務上通常已有指導教授指導、且
  累積了一定的研究成果(投稿中或已刊登的論文)才會申請；發表分流門檻依
  「預計畢業年資」而不同(在學年資越短，門檻期刊層級要求越高)。
- **餵給誰**：通過學術著作審查是申請「博士論文口試」的前提條件之一
  (SKILL.md reference_rules 明列「須先通過學術著作審查」)；也是「博士候選人
  資格考核會」的申請前提。
- **常見卡點**：
  - 每學期初召開，若投稿的期刊審查週期拖長、來不及在申請當學期完成
    正式接受(accepted)，可能要延到下學期才能申請，形成連鎖延誤。
  - 發表分流門檻與「預計畢業年資」綁定，若中途調整畢業時程規劃(如原本
    想 3 年畢業改成 5 年)，門檻要求跟著改變，需重新確認自己適用哪一級
    門檻，不能沿用舊的假設。

### 關卡 5｜博士候選人資格考核會（論文初稿、前三章口試）

- **依賴什麼**：實務上通常要求已完成大部分學分、有指導教授、且已具備
  論文前三章(緒論、文獻回顧、研究方法)的初稿——這是「候選人資格」的
  核心精神：證明你已經把研究問題想清楚、方法設計站得住腳。
- **餵給誰**：通過後才具備「博士候選人」身分，是「博士生論文研討」與
  「博士論文口試」的前提。**每學期至多一次**的機會限制，一次沒過會直接
  影響半年以上的時程。
- **常見卡點**：
  - 口試前三週繳申請書的窗口容易與工作行程衝突(在職生尤其)，建議在
    論文前三章初稿完成度達七八成時就先預排口試時程，而不是等初稿完全
    定稿才開始安排行政流程。
  - 2/3 委員同意為通過的門檻，代表即使多數委員支持，若委員意見分歧過大
    仍可能不通過——前三章的方法論嚴謹度(尤其研究方法一章)是委員最常
    要求修改的部分，建議提前請指導教授把關方法論章節。

### 關卡 6｜博士生論文研討（校外公開發表，三峽）

- **依賴什麼**：SKILL.md reference_rules 未明列此關與候選人資格考核會的
  強制先後順序，但實務上多數學程會安排在取得候選人資格之後，因為論文
  研討發表的內容通常就是已通過前三章口試的研究架構往下延伸；**若使用者
  手上簡章明列不同順序，以簡章為準**。
- **餵給誰**：是論文口試前，讓論文接受校外公開檢視、蒐集意見修正的機會，
  某種程度上是論文口試的預演。
- **常見卡點**：
  - 發表前三週申請、前三天交 PPT 的行政窗口，若同時間有工作出差安排，
    在職生特別容易措手不及，建議把這兩個窗口期直接標進行事曆提前規劃。

### 關卡 7｜博士論文口試（校內）

- **依賴什麼**：明確前提是「須先通過學術著作審查」；口試前一個月申請。
  這是全鏈的最後一關，也是唯一同時掛勾兩個前置條件(著作審查通過＋
  候選人資格已取得)的關卡。
- **餵給誰**：通過即完成畢業口試門檻，加上其他畢業條件(學術倫理課程、
  國際素養)後即可畢業。
- **常見卡點**：
  - 全體委員平均 70 分以上及格，但若 1/3 委員未達 70 分即不及格——這是
    「雙門檻」規則(平均分數門檛與個別委員門檻並存)，容易只注意平均分
    卻忽略個別委員的低分風險，建議口試前確認每位委員對論文的疑慮是否
    已充分溝通處理。
  - 口試前一個月的申請窗口，加上「須先通過學術著作審查」的前提，若著作
    審查是在同一學期較晚才通過，可能來不及湊滿一個月的申請前置期，
    需要跨學期規劃。

## 三、非研究關卡（不在主鏈上，但會卡畢業）

- **學術倫理課程**：無強制排序，但建議及早修畢，避免留到最後才發現這項
  尚未完成而卡畢業手續。
- **國際素養(累積點數)**：需要長期累積(如參與國際研討會、外語能力證明等
  依系辦規定認定的項目)，越早開始規劃越不會在畢業前臨時抱佛腳。

## 四、給在職生的相依鏈風險提醒

1. **窗口期關卡最危險，不是時間長的關卡最危險**：資格考申請指導教授
   （通過後1個月）、候選人資格考核會（口試前3週申請）、論文研討
   （發表前3週申請）這幾個「短窗口」關卡，比修業年限（以年為單位）
   更容易在忙碌的在職生活中被錯過——時間長的關卡有心理餘裕感，短窗口
   反而容易掉以輕心。
2. **著作審查是全鏈中最不可控的一關**：因為依賴外部期刊的審查週期，
   不是自己努力就能加速的部分，建議把投稿時程往前抓，不要等到需要
   申請著作審查前才開始投稿。
3. **相依鏈是「必要」不是「建議」順序**：本檔列出的順序是規則要求的
   先後依賴，不是「比較好」的建議做法，跳過或打亂順序（如在通過資格考
   前就想申請候選人資格考核會）在系統上通常無法成立，發現卡關時先確認
   是否誤解了相依關係，而非規則本身有問題。
