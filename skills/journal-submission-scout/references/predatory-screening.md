# 掠奪性期刊篩查（投稿前必做）

**這是本技能最重要的一份文件。** 投錯一本掠奪性期刊，代價不是幾百美元，
而是那篇論文**再也不能投別處**（已發表）、寫進履歷會被審查委員質疑、
甚至影響升等與計畫審查。

---

## 一、先破除三個誤解

| 誤解 | 事實 |
|---|---|
| 「有 ISSN 就是正規期刊」 | ISSN 只是**識別碼登記**，不做品質審查。掠奪性期刊都有 ISSN |
| 「網站上寫有 Impact Factor 就沒問題」 | 掠奪性期刊常標**假的**指標（如 "Global Impact Factor"、"Cosmos IF"）。真正的 JIF 只出現在 Clarivate JCR |
| 「收 APC 就是掠奪性」 | **錯得最嚴重**。正規的開放取用期刊也收 APC（SMJ 的 APC 是 3,860 美元）。**收費不是判準，收費後不做審查才是** |

---

## 二、工具能給的訊號（客觀、可查）

`journal_scout.py` 的「風險」欄把三個客觀訊號濃縮成提示：

| 訊號 | 為什麼可疑 |
|---|---|
| 收 APC 但不在 DOAJ | DOAJ 有審查門檻（需揭露審查制度、編委、授權）。收錢卻沒通過，值得追問 |
| h-index < 20 但收稿量 > 3000 | 量大而影響力低——「照單全收」的典型樣態 |
| APC > 3000 USD 且 h-index < 50 | 收費與品質不相稱 |

**⚠️ 訊號不是證據。** 老牌訂閱制頂刊本來就不在 DOAJ（SMJ、AMJ 都不在），
會被計一分，那完全正常。**分數只決定你先查哪一本，不能拿來下結論。**

## 三、人工核對清單（Think.Check.Submit 架構）

工具查不到的部分，以下逐項自己查。**任一項答不出來，就不要投。**

### Think — 你認識這本期刊嗎
- [ ] 你或你的指導教授、同領域同事**讀過**這本期刊的文章嗎？
- [ ] 它在你的參考文獻裡出現過嗎？（自己都沒引過的期刊要警覺）
- [ ] 它是**主動寄信邀稿**來的嗎？→ 🚩 掠奪性期刊最常見的獲客方式

### Check — 逐項查證

**編輯委員會**
- [ ] 編委名單有列出**姓名與所屬機構**嗎？（只有名字沒有單位 → 🚩）
- [ ] 隨機挑 2–3 位編委，Google 查證**他們本人的機構頁面**是否確實掛名
      → 🚩 掠奪性期刊常盜用學者姓名，當事人根本不知情
- [ ] 主編是誰？查得到他的學術履歷嗎？

**審查制度**
- [ ] 網站有明確說明**審查流程與週期**嗎？
- [ ] 🚩 **承諾「1 週內接受」「快速審查」** → 正常同儕審查做不到
- [ ] DOAJ 有收錄的話，看它登記的 review process（本工具會顯示）

**收錄與索引**
- [ ] 宣稱被 SSCI／SCIE 收錄 → **到 Clarivate Master Journal List 自己查**，
      不要信它網站上的圖示
- [ ] 宣稱被 Scopus 收錄 → 到 Scopus Source List 自己查
- [ ] 🚩 網站掛著 "Google Scholar 收錄" 當賣點 → Google Scholar 幾乎收錄一切，
      這不構成品質背書

**費用與流程透明度**
- [ ] APC 金額在**投稿前**就查得到嗎？（🚩 接受後才告知金額）
- [ ] 有沒有「撤稿費」「加急費」這類非常規收費？→ 🚩
- [ ] 版權與授權條款寫清楚了嗎？

**聯絡與所在地**
- [ ] 有**機構信箱**還是只有 Gmail／Yahoo？→ 🚩
- [ ] 地址查得到嗎？Google 街景是不是住宅或空地？→ 🚩

### Submit — 最後確認
- [ ] 這本期刊**確實刊登過你這個主題**的文章嗎？（讀近兩年目次）
- [ ] 你的指導教授同意投這本嗎？
- [ ] 如果被接受，你願意在履歷與口試場合說出這本期刊的名字嗎？

## 四、台灣脈絡的補充

- **系所認列**：投稿前先確認貴系所的著作審查是否認列該期刊。
  有些系所只認 SSCI／TSSCI，投了不認列的期刊等於白做。
- **TSSCI**：台灣社會科學引文索引，由國科會維護。要查是否為 TSSCI 期刊，
  到國科會的正式清單查，不要信期刊自稱。
- **國科會計畫結案**：計畫成果若掛在掠奪性期刊，審查時會被質疑。

---

## 五、如果你已經投了才發現不對

1. **立即撤稿**——在被接受前撤稿通常沒有代價
2. **不要付費**——已被接受但未付 APC，仍可拒付並要求撤稿
3. **保留所有往來紀錄**——若對方以「已接受」為由索費或威脅，紀錄是你的保護
4. 已經發表的話，誠實面對：**不要在履歷隱藏，也不要重複投稿到別處**
   （那會變成一稿多投，問題更大）

## 六、本技能的分工界線

| 誰做 | 做什麼 |
|---|---|
| `journal_scout.py` | 給客觀指標與**風險訊號**，決定你先查哪幾本 |
| **本文件（你自己）** | 逐項人工核對，**做出判定** |
| `q1-journal-reviewer` | 稿件本身夠不夠格投那個層級 |
| `phd-researcher` | 評估你**讀到的**論文所在期刊的等級（讀者視角） |

**工具永遠不會替你判定一本期刊是不是掠奪性的。** 那需要看網站、查編委、
讀目次、問指導教授——這些都是人的判斷。工具只能幫你把可疑的排到前面。
