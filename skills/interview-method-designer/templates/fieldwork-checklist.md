# 訪談執行檢核表（訪前／訪中／訪後）

> 對應 SKILL.md Step 5「執行與記錄雙軌」。每次訪談前列印或複製一份，逐項打勾；
> 未完成項目不得跳過進到下一階段（尤其知情同意與錄音確認）。

## 訪前準備（出發／上線前 1 天 ～ 當天）

- [ ] 知情同意書已備妥（紙本簽署或電子同意流程），內容為最新修訂版本
- [ ] 訪談大綱為最新定稿版（含 pilot 修訂後版本，非草稿版）
- [ ] 錄音設備已測試（電量、儲存空間、備用錄音裝置——建議雙錄音以防單一設備故障）
- [ ] 若為視訊訪談：已測試錄影／錄音功能、確認網路環境、告知受訪者若中斷的備案
- [ ] 受訪者代號已預先指派（如 P01），避免訪談中不慎講出真名於錄音檔
- [ ] 訪談地點／視訊連結已與受訪者二次確認（含時區換算，若跨國訪談）
- [ ] 已準備田野筆記表（紙本或電子），供訪談中速記非語言訊息

## 訪中執行

- [ ] 訪談開始前完成知情同意程序（口頭覆述重點：錄音授權、匿名化、退出權），
      確認受訪者理解後才開始錄音
- [ ] 錄音已實際啟動（開場後立即口頭確認錄音時間戳，防止「以為在錄但其實沒錄」）
- [ ] 暖身區塊確實執行、不直接跳進核心問題（見 `templates/interview-guide-template.md`）
- [ ] 追問聚焦具體事件與經驗細節，不覆述研究者自己的假設請受訪者附和
- [ ] 訪談時間控制在預計範圍（60–90 分鐘），中途留意受訪者疲態並可提議休息
- [ ] 收尾區塊的開放式問題（「有沒有我沒問到但您覺得重要的？」）確實提出
- [ ] 訪談中即時記錄關鍵詞筆記（作為錄音備份與後續辨識重點段落的索引）
- [ ] 結束前再次確認後續聯繫方式與逐字稿確認意願

## 訪後 24 小時內（田野筆記為 reflexivity 原料，逾時記憶會失真）

- [ ] 田野筆記已完成，內容涵蓋：
  - 訪談情境（地點、氛圍、有無第三人在場或干擾）
  - 非語言訊息（語氣轉折、停頓、明顯的情緒反應）
  - 研究者自我反思（本次訪談中，研究者的提問或身分是否可能影響受訪者回答；
    有無預設立場被挑戰或印證）
- [ ] 錄音檔已備份至加密儲存位置，並依代號＋日期命名（如 P01_20260115.m4a）
- [ ] 逐字稿轉錄已安排（自行轉錄或委外，委外需簽保密協議）
- [ ] 逐字稿規格已對轉錄者說明：全逐字含語氣詞、標記說話者、每 5 分鐘一個時間戳、
      匿名化在轉錄階段即完成（真名、公司名、可識別地名一律以代號替換）
- [ ] 受訪者資訊表已更新（代號、關鍵特徵、訪談時長、地點形式）——投稿必附

## 資料品質與倫理雙重確認

- [ ] 本次訪談所有錄音使用皆有知情同意涵蓋範圍內（未逾越同意書載明用途）
- [ ] 若受訪者要求刪除部分內容或整體退出，已在此欄位記錄處理結果與日期
- [ ] 若為組織內引介受訪者，已確認訪談內容未回流給引介者（防火牆條款落實）
