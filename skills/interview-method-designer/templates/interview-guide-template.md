# 半結構式訪談大綱模板

> 使用方式：複製本模板到你的研究專案，逐區塊填空。填完後對照文末「禁誘導詞自檢表」
> 逐題檢查一遍，再送 pilot（試訪 1–2 人）。本模板對應 SKILL.md Step 2 的三層結構：
> **主題區塊 → 每區塊主問題 → 備用追問**。

## 暖身區塊（不進核心，5–10 分鐘）

目的：建立 rapport，讓受訪者放鬆並確認基本背景，不涉及研究核心問題。

1. 請簡單談談您目前的職位與主要工作內容。
2. 您在這個角色／這家公司多久了？

（追問備用：能否談談您是怎麼開始接觸這個領域的？）

## 收尾區塊（必放）

1. 「有沒有我沒問到、但您覺得對這個主題很重要的事情？」
2. 「如果我後續有問題需要再跟您確認，方便再次聯繫嗎？」
3. 感謝與說明後續（逐字稿是否會回饋確認、預計研究產出時程）。

## 禁誘導詞自檢表（送出前逐題比對）

| 檢查項 | 說明 | 通過？ |
|---|---|---|
| 是否有「是不是因為…」開頭的主問？ | 已預設答案方向，必須重寫為開放式敘事問句 | ☐ |
| 是否有「您會不會覺得…」「有沒有覺得…」？ | 誘導受訪者附和，改為「您怎麼看待…」 | ☐ |
| 主問題是否為封閉式（可用「是／否」回答）？ | 封閉式不屬於半結構訪談主問，若需要就降級為追問或前測題 | ☐ |
| 主問題是否要求受訪者評價研究者的假設？ | 訪談是聽故事不是求印證，改為請其描述經過 | ☐ |
| 追問是否只追經驗細節（誰／何時／怎麼發生），沒有替受訪者下結論？ | 追問不搶主問的敘事權 | ☐ |
| 順序是否遵循「暖身→具體事件→抽象反思→收尾」？ | 一開始就問抽象評價容易得到場面話 | ☐ |
