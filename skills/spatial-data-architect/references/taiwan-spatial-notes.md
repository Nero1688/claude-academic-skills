# 台灣空間資料實務筆記(座標、行政區、資料源)

## 座標系統(最重要)

| 系統 | EPSG | 單位 | 誰在用 |
|---|---|---|---|
| WGS84 | 4326 | 經緯度(度) | GPS、Google Maps、多數 API、H3 |
| TWD97 TM2(中央) | 3826 | 公尺(投影) | 台灣官方圖資、國土測繪、部分政府開放資料 |
| TWD97 經緯度 | 3824 | 度 | 少數官方經緯度資料 |
| TWD67 | 3828 | 公尺 | 舊圖資(遇到要先確認) |

**判別**:數值是 22~26 / 120~122 這種兩三位數 → 經緯度(WGS84/3824);
是 24xxxxx / 3xxxxx 這種六七位數公尺 → TWD97 投影(3826)。

轉換(pyproj):
```python
from pyproj import Transformer
# TWD97(公尺)→ WGS84(經緯度);always_xy=True 讓輸入輸出都是 (x=經度/E, y=緯度/N)
tf = Transformer.from_crs("EPSG:3826", "EPSG:4326", always_xy=True)
lng, lat = tf.transform(E_meters, N_meters)
```
`spatial_aggregate.py` 內建 WGS84 範圍檢查,抓到未轉換的 TWD97 會擋下並提示。

## 行政區代碼與界線

- **行政區代碼**:內政部有標準區碼(縣市 2 碼、鄉鎮市區 8 碼);跨年度有合併改制
  (如縣市升格、鄉鎮改區),做時間序列要對齊代碼版本。
- **界線圖資**:國土測繪中心/政府資料開放平台有鄉鎮市區界 shapefile(通常 TWD97);
  choropleth 底圖用它。取得走 台灣官方統計來源。
- **點面判斷**(座標落在哪個區):geopandas 的 `sjoin`(spatial join)最直接。

## 不動產空間資料源(接 台灣官方統計來源)

- **實價登錄**(plvr.land.moi.gov.tw):成交價、面積、屋齡等;地址官方去識別到**路段**
  (非門牌),所以座標是路段級——研究要誠實說明這個粒度限制。撈取用 台灣官方統計來源
  的 `plvr_realprice.py`(注意該站需 .gov.tw TLS 相容層)。
- **不動產成交案件實際資訊**、**預售屋**:MOI 另有專案,涵蓋逐年擴大。
- 地價、公告現值:地政單位開放資料。

## hedonic 房價研究的空間注意事項

1. **空間自相關幾乎必然存在**:鄰近房價互相影響;純 OLS 的標準誤會低估,係數可能偏誤。
   先跑 Moran's I,顯著就走空間迴歸(交 r-spss)。
2. **空間權重 W 要理論化**:房價外溢是「距離」還是「同社區/學區」?W 定義要對應機制,
   別因方便就用預設。
3. **鄰近設施**:捷運站、學校、公園距離是 hedonic 常見變數——需要地理編碼設施點 +
   算最近距離(本 skill 的地理編碼驗證同樣適用)。
4. **粒度一致**:實價登錄是路段級,若鄰近變數是門牌級,粒度不一致要交代。

## 隱私與法遵

- 個別門牌座標可識別住戶;分析與釋出用網格(H3)或路段級,不建門牌級可識別彙整檔。
- 抓政府圖資與實價登錄:守站台服務條款與政府資料開放授權;沿用家族抓取紅線
  (禮貌間隔、不硬爬、.gov.tw 走 TLS 相容層)。
