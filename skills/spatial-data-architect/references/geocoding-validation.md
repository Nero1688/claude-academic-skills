# 地理編碼 + 驗證退路(防幻覺座標)

地址→座標是空間研究的資料入口,也是最容易被 AI/服務悄悄污染的一步。
核心紀律:**任何自動地理編碼的結果都要驗證才能用**——這與 text-analytics-architect
的「LLM 標註要有人工基準」同源。

## 地理編碼來源與取捨

| 來源 | 優點 | 風險 |
|---|---|---|
| 政府 TGOS 地址定位 | 台灣官方、權威 | 需查當期服務條款與額度 |
| Google/商業 Geocoding API | 涵蓋廣、容錯好 | 需金鑰付費;ToS 限制(結果不可長期儲存者要看清楚) |
| LLM(GPT/Claude)地理編碼 | 處理模糊地址、地名 | **會直接編一個看似合理的座標**——最危險 |
| 實價登錄自帶座標 | 免地理編碼 | 官方去識別到「路段」,非門牌精確點 |
| OSM Nominatim(公共伺服器) | 免金鑰、全球涵蓋、開放資料 | 依其使用政策:約每秒 1 次上限、禁止系統性大量批次、須以 User-Agent 識別;資料為 ODbL,地理編碼結果彙成資料庫公開釋出時可能須以相同授權分享。**中文門牌命中率先小樣本實測再決定** |

金鑰一律走環境變數,不硬編碼(沿用家族紀律)。

**別被「Geocoding」分類名誤導**:公開 API 清單(如 public-apis)的 Geocoding 類,
多數條目其實是「IP 位址定位」(查訪客在哪個國家),與「地址→座標」無關,不能拿來做研究的地理編碼。
跨國研究時,優先找**該國官方地址登記庫**提供的服務(部分國家的政府有官方地址查詢 API),
台灣則以 TGOS 為主。

## 四道驗證退路(全部要做)

1. **行政區約束(最有效)**:地址已知在「台北市大安區」,回傳座標必須落在大安區
   界內。落在區外 → 幾乎確定錯,標記人工複核。用行政區界 shapefile 做點面判斷。
2. **合理範圍**:座標落在台灣經緯度範圍外(緯度非 21.5–26.5、經度非 118–122.5)
   → 直接離群。
3. **距中心點過遠**:座標距該行政區形心超過該區半徑數倍 → 疑似錯配。
4. **抽樣人工核對**:隨機抽 30 筆,把座標貼回地圖對地址,報一致率;一致率過低
   → 回頭查地理編碼來源,不默默用。

## 座標編碼與格點檢查(四道退路之前先做)

拿到「別人的座標欄」時(政府排放清冊、設施名錄、氣象 API),先排除四種編碼陷阱——
它們都不會報錯,只會讓點默默落到錯的地方:

1. **經度正負號**:西半球資料可能把西經存成正值(該是 −72 卻存 72)。檢查經度符號與
   該筆所屬國家是否一致;一上圖就落在另一個半球的,幾乎都是這個。
2. **度分秒打包成整數**:六、七位整數不一定是 TWD97 公尺,也可能是 DDMMSS 壓縮
   (441221 = 44°12′21″)。看欄位說明;換算為 `度 + 分/60 + 秒/3600`。
3. **格點吸附**:網格化資料(氣象模型、再分析、遙測)回傳的是**格點座標**,不是你請求的點。
   以回傳座標作為該變數的空間單位;鄰近樣本共用同一格點值,標準誤依格點叢集,
   不要把「樣本多」當成「空間變異多」。
4. **空結果就是失敗**:地理編碼回空陣列是「沒編到」,不是「地址不存在」。記
   `_geocode_method=failed`,報告失敗率,並檢查失敗是否集中在特定區域或地址型態——
   集中就是非隨機遺漏,直接丟掉會造成選擇偏誤。

另外留意**精度欄**:部分資料逐筆附座標精度(公尺),同一檔內可差兩個數量級;
做近距離比對(如「距捷運站 500 公尺內」)前先按精度篩。

## LLM 地理編碼的特別防線(若非用不可)

- **白名單約束**:把「合法可能的行政區/地名清單」給 LLM,要它只能從清單選,
  不能自由生成座標。(mini-taiwan-pulse 的作法:368 個鄉鎮白名單 + 中心點回退。)
- **回退(fallback)**:LLM 給不出可信結果時,回退到「該行政區中心點」並明確標記
  `_geocode_method=centroid_fallback`,而不是硬給一個門牌級假座標。
- **絕不讓 LLM 的座標未經上述驗證就進最終資料集**——這是資料造假的灰色地帶。

## 譜系與揭露

- 每個座標記三欄:`_geocoder`(來源)、`_geocode_method`(precise / centroid_fallback / manual)、
  `_asof`(時點)。呼應 multi-source-data-integrator 的來源譜系。
- 論文方法節寫明:地理編碼來源、驗證程序、fallback 比例、抽樣一致率。
- 隱私:門牌級座標可識別個別住戶/交易;分析與釋出用網格或路段級,不建門牌級可識別檔。
