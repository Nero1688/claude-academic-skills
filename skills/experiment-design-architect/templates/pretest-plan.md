# 前測(Pilot Test)計畫模板

> 對應 SKILL.md Step 4「前測、操弄檢核、檢定力」。核心原則：**前測失敗就改材料，
> 不硬上**——前測不是走流程，是給自己一次用小樣本、低成本抓出材料問題的機會。

## 一、前測目的（勾選本次前測要檢查的項目）

- [ ] 操弄是否有效（操弄檢核通過率是否達標）
- [ ] 情境擬真度是否足夠（僅適用於情境實驗，見 `templates/vignette-template.md`）
- [ ] 完成時間是否合理（過長會影響正式施測的注意力與回收率估算）
- [ ] 指導語與題項是否有理解困難（開放題蒐集受試者的困惑反饋）
- [ ] 依變數量表的信度是否可接受（若為多題項量表）

## 二、樣本規劃

- 每個 cell（條件組合）建議 15–20 人，前測不追求檢定力，追求「足夠看出材料問題」。
- 招募管道：〔便利樣本／MTurk／學生樣本等，說明理由與可能的外推限制〕
- 前測樣本**不得**與正式施測樣本重疊（避免同一批人对材料失去新鮮感或产生练习效应）。

## 三、前測執行清單

- [ ] 材料版本已定稿（所有條件版本已逐字比對過，見 vignette-template 檢查清單）
- [ ] 操弄檢核題、擬真度題已附在前測問卷中（正式施測可視結果決定是否保留擬真度題）
- [ ] 完成時間計時機制已啟用（問卷平台的作答時間戳，或口頭計時）
- [ ] 前測問卷結尾加開放題：「以上情境或問題敘述，有沒有讓您感到不清楚或奇怪的地方？」
- [ ] 前測知情同意與倫理程序與正式施測一致（前測本身也是人類受試者研究）

## 四、判準與決策規則（先訂，不要看到結果才決定「這樣算過了」）

| 檢查項 | 通過門檻 | 未通過時的處置 |
|---|---|---|
| 操弄檢核通過率 | 條件間知覺分數的 t/F 檢定顯著，且方向符合預期；建議個別通過率 ≥ 70% | 加強操弄字句的顯著性（如加入具體數字或更強烈措辭），重新前測 |
| 情境擬真度 | 均值 ≥ 5（7 點量表） | 回頭修改情境骨架细节描述，使其更貼近母體樣本經驗，重新前測 |
| 完成時間 | 落在預期範圍內（如 5–10 分鐘），且各條件間無系統性差異 | 精簡題項或情境長度；若某條件明顯較長，檢查是否該條件文字冗贅 |
| 理解困難（開放題） | 無多人反映同一處看不懂 | 修改該處措辭，用更口語化的表達重寫 |
| 量表信度（如適用） | Cronbach's α ≥ .70 | 檢查反向題是否誤植、題項是否偏離構念定義 |

## 六、前測通過後的交棒

- [ ] 前測結果與修訂紀錄已整理成方法節附錄材料（審稿人常要求說明前測過程）
- [ ] 定稿材料已凍結版本（不再修改），與正式施測的隨機分派設計（見
      `references/counterbalancing.md` 與 `scripts/latin_square.py`）銜接
- [ ] 先驗檢定力分析（SKILL.md Step 4）已用正式施測前的效果量估計（可參考本輪
      前測的操弄檢核效果量作為輔助佐證，但正式檢定力分析仍以前人研究或 meta
      分析的效果量為主，不能只用前測小樣本效果量直接推算）

## 常見錯誤

1. 前測樣本數就拿來做正式分析，混用資料——前測與正式施測必須是不同批受試者。
2. 操弄檢核沒過還是硬著頭皮跑正式施測，指望正式施測人數多會「自動顯著」——
   操弄本身無效時，樣本再大也救不回來，必須先修材料。
3. 只做一輪前測就假設一定會過，沒有為第二輪前測預留時間——前測本來就可能需要
   2 輪以上，時程規劃時要抓緩衝。
