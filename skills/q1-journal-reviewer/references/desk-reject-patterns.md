# 桌拒攻擊清單（Desk-Reject Patterns）

> 本檔補的是 `SKILL.md` 五個維度沒有涵蓋的那一層。
> 五個維度問的是「這篇做得好不好」；本檔問的是「這篇**還沒被讀就會被退**嗎」。
>
> 依據是一批實際退稿信的歸因分析（18 次退稿，持續累積）：**超過一半（56%）的退稿與論文品質無關。**
> 資料、識別、穩健性從來不是被點名的問題，被點名的是定位、受眾與體例。
> 一篇識別乾淨、穩健性做滿的稿子，照樣會在編輯手上停留六天然後回一封零意見的信。
>
> 使用方式：對每一條做出**是／否**的判定並附證據，不要寫「大致沒問題」。

---

## D1 受眾錯配（最高頻，佔已知退稿 56%，10/18）

「範圍過於狹窄」「不夠新」「貢獻過於增量」「本刊讀者是實務端」這幾句退稿詞，
**往往不是在說論文不好，是在說讀者不對。** 編輯是替訂戶讀稿的。

**可量化的診斷：數參考文獻的學科組成。** 編輯掃一眼清單就知道這是哪一科的論文。

- [ ] 把參考文獻依學科分類，算出各科佔比。目標刊主場學科佔比低於六成 → 紅燈。
- [ ] 目標刊**自己刊過**的文章，本稿引了幾篇？零篇 → 紅燈。這是最常被編輯直接點名的一項。
- [ ] 本稿要推進（不是順手引用）的三到五篇核心文獻，發表在哪些刊？那幾本才是該投的。
- [ ] 目標刊近三年有沒有登過**引用那三到五篇**的文章？沒有 → 契合度不能寫成高。
- [ ] 目標刊實際刊出的題目做關鍵詞命中率，不要只看範疇頁。**範疇頁的關鍵詞不等於受眾。**

**受眾盤點數的是「題目」，不是「技術」。** 方法傳統對口不等於題目對口。
- [ ] 用 Crossref 拉目標刊近三到四年**全部題名**，數**本稿主題**（不是本稿用的技術）的命中率。
      **典型失敗**：某刊的技術傳統（門檻、鎖定、路徑依賴）與本稿完全相同，
      但其近四年 319 篇題名裡本稿主題只佔 1%；配到編輯當日桌拒：
      「not well suited for our readership… find a journal that focuses on these topics in a more direct way」。

**主辦機構有立場的期刊，不投與其立場相左的結論。**
- [ ] 查該刊由誰主辦。主辦機構若對本稿檢驗的政策有明確立場，而本稿結論與之相左，別投——
      退稿理由會寫成「不合本刊」，不會說出真正原因。
      **典型失敗**：同一篇被綜合刊說「太窄」、被領域刊說「不合」，理由互斥；後者的主辦機構正好對該政策持相反立場。

**題面反射。** 高流量刊的主編對「三個當紅政策關鍵詞串成的題目」會反射性桌拒，不讀摘要第二句。
- [ ] 同一篇在短期內被同集團兩本刊以**互斥理由**（不夠新 vs 不合範疇）一日桌拒——理由互斥本身就是題面反射的證據，不是稿子的問題。
- [ ] 對策：題目以**量測結果**開頭、拿掉時髦關鍵詞串；投稿信第一句講一般性結論，不講單一國家；改投初審會讀內文的刊。

**典型失敗**：某刊範疇頁寫「應用賽局」，稿件是動態公共財自願提供，被評為契合度高。
該刊實際的主場是廠商競爭策略與產業組織，稿中沒有市場、沒有價格、沒有產品市場競爭。
六天桌拒、主編署名、零意見。

**典型失敗二**：理論脊椎在法律經濟學，卻因為借用了治理理論的架子而投治理刊。
退稿理由「對本領域理論貢獻有限」——完全正確。

## D2 未查處理編輯的專長

- [ ] 查過主編與該領域副主編的近三年著作了嗎？
- [ ] 本稿**未 engage** 的文獻，有沒有正好是某位副主編的代表作？
- [ ] 稿中有沒有對某一片文獻寫「據我們所知尚無人…」，而那片文獻的代表學者就是處理編輯？

**受眾對、守門人錯。** 批判某類研究設計的方法論論文，投到**刊登該類設計**的高流量刊，主編不會把
「你們的設計量錯了」當成新發現——會回「不夠新」，與理論刊對方法批判的反應同型。
- [ ] 方法論批判要投**量測方法本身是核心讀者**的刊。受眾對了，還要看誰在守門。

**典型失敗**：稿件文獻回顧十四篇全是開發中國家案例，並寫著「no one has exploited
this configuration」。處理的副主編正是已開發國家該主題文獻的代表學者，退稿信寫
「需要與該文獻更直接的對話，以釐清貢獻並交代設計動機」。

## D3 反面搜尋沒做

- [ ] 每一個「本文首度／據我們所知尚無」的宣稱，都做過一次**專門找反例**的搜尋嗎？
- [ ] 找到的反例寫進文獻回顧了嗎？
- [ ] 查不到才可以寫，且要用可被推翻的措辭（「we are not aware of」而非「there is no」）。

向某文獻的作者宣稱該文獻不存在，是自曝其短，且無法補救。

## D4 限制的擺位與語氣

**不要把限制寫成可以直接剪貼進拒稿信的句子。**

- [ ] 測度效度的限制在**限制節或方法節**，不在結果節開頭。結果節講結果。
- [ ] 用界定範圍的語氣，不用認錯的語氣。
      寫「本文的證據涵蓋 X；Y 不在其射程內」，不要寫「這是對主張的實質限制」。
- [ ] 掃描全稿，禁用這些字修飾自己的證據：`only`、`merely`、`suggestive rather than`、
      `not clean`、`we do not have`、`a real limit on`。這些字眼會被原句引用。
- [ ] 虛無結果的論文特別危險：可信度全靠測度品質，此時自陳失敗等於先替審稿人下判決。

**典型失敗**：拒稿信的核心句幾乎是原稿的原文——「the authors themselves acknowledge
that their validation is only suggestive rather than decisive」。編輯沒有自己找出問題，
是照抄作者寫的。

**這條不是准許遮掩。** 該講的限制一項不少；差別只在擺位與語氣。

## D5 包裝與摘要排序

編輯讀不到就歸檔。

- [ ] 摘要**前三句**是本文真正新的東西，還是已知機制的鋪陳？
- [ ] 標題有沒有把已知現象放在主位、把新發現放在副標？
- [ ] 若本文的機制是既有文獻已知的，那三個真正新的**後果**有沒有排在前面？

**典型失敗**：標題與摘要第一句都在講一個市場微結構的既定現象，三個真正新的後果
（跨國排名翻轉、假異象、假政策效果）排在第 5–8 句。退稿理由：「該現象是既定的，
概念貢獻過於增量」——事實對、推論錯，但編輯不會讀到第 5 句。

## D6 假說結構

- [ ] 每一條假說都是**可否證的實質預測**嗎？
- [ ] 有沒有把**估計方法**寫成假說？（「本文以三重差分而非子樣本比較檢定 X」不是假說，是方法。）
- [ ] 有沒有把**穩健性檢查**寫成假說？（「以另一資料源檢驗結果不變」不是假說。）
- [ ] 有沒有一條假說綁了三個以上的預測？拆開。
- [ ] 每條假說前面有沒有**實質的理論推導**，還是只有一句轉折句？
- [ ] 競爭假說有沒有寫成真正的對立預測（H2a／H2b），讓資料去裁決？

**典型失敗**：七條假說裡兩條不是假說、一條綁了三個預測，每條前面只有一句條件句。
退稿理由第二條就是「假說未經充分理論發展」。

## D7 文獻規模

- [ ] 參考文獻筆數與目標刊的常態相符嗎？管理與商業倫理刊常見 60–120 筆。
- [ ] **編輯是真的會去數的。** 一次退稿理由的第一條就是「參考文獻過於單薄」。
- [ ] 每一筆都被正文引用了嗎？文獻表裡躺著沒被引的條目，是「文獻是湊數的」最明顯的跡象。
- [ ] 反向也要查：正文引的每一筆都在文獻表裡嗎？

---

## D8 體例與投稿介面

這一層不影響學術品質，但會讓稿子在進入審查前就被退回。

- [ ] **編輯部的個別指示優先於作者指南的通用結構。** 指南自己前後矛盾時，
      以 Formatting 節與編輯部來信為準。
- [ ] 匿名政策要**查證附出處**，不可從投稿樣板的條件句推斷。
      樣板寫「If the journal uses double-anonymous review…」是條件句，不是宣告。
- [ ] 表與圖該不該放進主檔？不同刊相反，且同一份指南可能自相矛盾。
- [ ] 圖檔命名、格式、解析度、字型；圖說編號後與結尾的標點。
- [ ] 表與圖在正文的**首次引用順序**必須遞增。改動編號後要重查文件裡**實際**的編號，
      不能只查正文引用順序（曾出現兩個 Table 8 而正文引用順序完全正確的情形）。
- [ ] **顯著性星號**與其圖例：改版時最容易整批消失，尤其當產檔程式會解析
      markdown 的 `*` 時。每張表都要有圖例，且要驗證產出的檔案而不是原始碼。
- [ ] 中繼資料（作者、last modified by、revision）；雙盲稿的黑名單掃描要自動化，不靠人眼。
- [ ] **作者名單對上一版投稿的標題頁逐字核對**：姓名、順序、ORCID、貢獻聲明。改投時建構器
      最容易把它預設成單一作者或漏掉共同作者；作者增刪在出版社系統有倫理追溯，不能靠事後補。
      這一項也要進 preflight 斷言，不靠人眼。

## D9 範疇排除條款

- [ ] 目標刊的 aims and scope 有沒有**明文排除**某類研究？逐字讀，包括括號裡的舉例。
- [ ] 若本稿疑似落在排除範圍，**在稿件內正面處理**，不要只寫在求職信裡。
- [ ] 排除條款的措辭要對照該刊**實際刊出的紀錄**。條款寫得寬、實務上寬容的情形很常見，
      反之亦然。用 Crossref 拉該刊全部標題來實測，不要憑印象。

**做法示範**：某刊排除「narrowly defined geographical samples (e.g., single cities or
regions)」。括號指的是次國家層級；實測該刊 1,047 篇裡有 80 篇標題直接點名單一國家。
於是在稿件中新增一節，論證受檢驗的是一套**法規架構**而非一個國家，並列出該架構的
四個組成在其他司法管轄區同樣存在。

## D10 自我攻擊時最該先查的地方

按投報率排序：

1. **自己貼的變數標籤。** 標籤貼錯會讓正確的數字讀起來像反證。
   （實例：把資料商的「主題評分」標成「揭露」，兩個不顯著係數看起來像
   「政策根本沒推升該領域的揭露」，整篇論證瞬間變成廢話。查清後改正，
   反而長出一條單調梯度，成為全篇最有力的一張表。）
2. **只報了對自己有利的那個設定嗎？** 若排除了某個估計量，要能自證排除不是擇利
   （例如：採用它反而會讓對照組係數變顯著）。
3. **同一節裡的自相矛盾。** 前段說「唯一的邊際結果」，後段說「四個面向都沒改善」。
4. **正文提到、表裡沒有的數字。** 反之亦然。
5. **虛無結果有沒有給最小可偵測效果？** 沒有的話，「精確的零」與「無力的零」讀者分不出來。

## 判定輸出

在 `SKILL.md` 的報告格式中，把本檔的發現寫進 **Major concerns**，並額外加一行：

```
桌拒風險：高／中／低
最可能的桌拒理由：<一句話，用編輯會寫的措辭>
```

若「最可能的桌拒理由」寫得出來且成立，那就是**投出去之前必須先解決的東西**，
其優先序高於任何穩健性檢定。
