# 論文「非統計圖」選型：先定論證角色，再定版式

`framework_figure.py` 只畫兩類圖：**假說路徑圖**（mediation／moderation 等五種 template）
與**樣本流程圖**（`sample_flow`）。論文裡其他常見的示意圖——第一章研究流程圖、類型學
2×2、多層次巢套、構念階層樹、政策時間軸——腳本不畫，但**畫法紀律一樣歸本技能管**：
本檔給選型判準與各版式的文法，實際用 PowerPoint／draw.io／Inkscape 依文法手繪，畫完
照 `visual-discipline.md` 的自檢清單逐條核。

## 一、先過三道門（任一道不過，就不畫圖）

1. **表格測試**：三欄表格說得清楚的，用表格（APA 7 表格格式）。變數操作型定義、文獻
   比較、假說彙總都是表，不是圖。
2. **段落測試**：一兩句話說得完的（兩個框一條線），寫成句子。
3. **目錄測試**（台灣學位論文最常見的毛病）：「第一章緒論 → 第二章文獻探討 → …」每個
   框只是章名的「研究流程圖」，其實是目錄。流程圖的框要是**研究動作**（界定問題、
   自 TEJ 擷取資料、建立樣本、估計模型、穩健性檢驗），不是章節標題。

## 二、選型表：讀者必須看懂什麼 → 用哪種版式

先說出「讀者看完要懂的那一件事」，再對表選版式。兩種版式都像可以時，挑**主軸**那一種
（因果方向？包含關係？時間？），另一種的資訊寫進圖註或拆第二張圖——**一張圖只用一套
版面文法**，不要混搭。

| 讀者必須看懂… | 版式 | 腳本 | 文法 |
|---|---|---|---|
| 變數之間的假說方向（X→M→Y、W 調節哪一段） | 假說路徑圖 | ✓ | `framework-figure-spec.md` |
| 樣本／文獻如何一步步篩到最終樣本 | 樣本流程圖 | ✓ | 同上 `sample_flow` |
| 研究執行的先後步驟（第一章研究流程） | 流程圖 | 手繪 | 三-1 |
| 依檢定結果走不同分支（Hausman → FE／RE） | 決策流程圖 | 手繪 | 三-1 |
| 層次包含（公司年⊂公司⊂產業；員工⊂團隊⊂公司） | 巢套圖 | 手繪 | 三-2 |
| 構念的階層拆解（構念→構面；文獻分類） | 樹狀圖 | 手繪 | 三-3 |
| 兩個維度交叉出四種類型（類型學） | 2×2 類型矩陣 | 手繪 | 三-4 |
| 兩三套理論的交集＝本研究的定位 | 文氏圖 | 手繪 | 三-5 |
| 政策或制度事件落在樣本期間的哪裡（DiD 處理時點） | 時間軸 | 手繪 | 三-6 |
| 已有係數、信賴區間、分布 | 統計圖 | — | 轉 `management-figure` |

## 三、各版式文法（含預算與反模式）

密度上限沿用 `visual-discipline.md`（節點 ≤10、連線 ≤14）；下列是各版式另加的上限。

### 1. 流程圖／決策流程圖

- **形狀表示種類，不靠顏色**：圓角長框＝起訖、長方框＝步驟、菱形＝判斷。全圖中性色，
  黑白印刷照樣讀得懂。
- 單一方向（上→下或左→右）；菱形最多 3 個出口，**每個出口都標條件**（是／否、p<.05）。
- 連線一律直角折線、轉角小圓角，不畫斜線；分支會合處用小實心點。
- 強調最多一處：本研究的貢獻步驟（如「自建○○指標」），或完全不強調。
- 反模式：框是章名（目錄測試）；菱形 4 個以上出口（改兩層判斷）；分支不標條件；
  用顏色分步驟種類。

### 2. 巢套圖

- 外層範圍大、內層較具體，3–5 層（上限 6）；層與層的內縮距離一致，不一致看起來像畫歪。
- 層級標籤放左上角、壓在邊框上（白底遮住那一小段框線）；可附該層樣本數，如
  「公司（N＝1,212）」。
- 框線由外而內漸重（細灰→黑）；強調只給最內層，或完全不給。
- 巢套圖只交代**資料結構**；跨層次假說（脈絡變數調節個體層路徑）仍用路徑圖畫，
  必要時兩張並列。
- 反模式：放進與層級無關的內容；多層都強調（層級感消失）。

### 3. 樹狀圖

- 根在上（或在左），連線走直角匯流排：父節點垂直下引 → 水平匯流排 → 子節點垂直接入。
- 深度 ≤4（根＋3 層）、每層 ≤5 個；超過就拆子樹另畫。框寬最多兩種；不跳層。
- 量表構念樹畫到**構面**為止，題項列表格——題項一多，樹就爆版。

### 4. 2×2 類型矩陣

- 每軸一個構念，構念名稱放軸外、只寫一次；兩端標「低／高」，不在文字裡夾箭頭符號
  或括號說明。（通用版是「軸端只寫一個字」；學術類型學慣例要標兩極，故改為此寫法。）
- 四格各自命名（如「壕溝型」「利益一致型」），不是「類型一」；格內 1–3 行說明。
- 格角編號標籤的用詞要與軸名逐字一致，例：軸名「控制權」「盈餘分配權偏離」，格標就寫
  「01｜高控制權／高偏離」——用詞對不上，讀者三秒就看出矛盾。
- 最多強調一格（本研究聚焦的類型），也可以不強調。
- 格內不放散點：若「格內位置」有意義，那是散佈圖，轉 `management-figure`。
- 反模式：四格塗四種顏色；3×3 硬壓成 2×2；軸名與格標用詞不一致。

### 5. 文氏圖

- 最多 3 個圈；4 個以上改用比對表。
- 只有各集合規模可比時才畫等大；規模不同就照比例，不為好看假裝一樣大。
- 集合名稱放圈外、不壓在圈線上；交集名稱放交集區內，區域太小就拉引線到空白處。
- 只強調一個交集：本研究的定位。
- 反模式：區域沒標名；圈根本不重疊卻用文氏圖。

### 6. 時間軸

- **刻度誠實**：事件間隔不等就畫成不等距，不為整齊假裝等距；某段太密就明顯斷軸。
- 事件點落在軸上，標籤上下交錯避免互撞；關鍵事件改用**不同形狀**（大實心點），不只換色。
- DiD／事件研究轉譯：標出樣本期間起訖、主管機關**公布日與生效日**（兩者不同要分開標）、
  前期與後期窗格；交錯採用（staggered）時一個採用世代一列，不要全擠在一條軸上。
- 反模式：等距排列不等距的事件；軸沒有時間單位；標籤擠成一團。

## 四、畫之前，一句話確認

動手前回報一句：「打算用○○版式、給○○用途（期刊／口試／海報，見 `output-tiers.md`）、
會收合或省略○○」，讓使用者在畫之前改方向。只有使用者已把版式、用途、內容都講死時才
省略這一步。
