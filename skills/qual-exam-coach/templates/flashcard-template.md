# 記憶卡空白模板與間隔複習追蹤表

> 對應 SKILL.md「記憶卡格式」與核心原則 4（間隔複習）。複製下方單卡模板，
> 每個理論填一張；卡片填完後登錄進文末的複習排程追蹤表，依 1/3/7/14 天
> 節奏回訪，不是讀完一次就丟。

## 單卡模板（複製此區塊，每理論一張）

```
【理論名 中/英】｜考點層級：必考/常考/冷門
一句話定義：<20 字內>
核心命題：① … ② … ③ …（2–3 個關鍵主張）
代表學者（年代）：<姓 年>；不確定標「需查證」
在跟誰對話：對立＝… ｜ 互補＝…
常見考法與陷阱：<考法類型 + 易錯點>
在地/實務連結：<台灣或亞太例，加分用>
複習：首見 __ ｜ 下次回訪 __（1/3/7/14 天）｜ 信心度 低/中/高
```

## 填卡檢查（每張卡完成後自檢）

- [ ] 「一句話定義」是否真的在 20 字內，而不是把核心命題硬塞進定義欄
- [ ] 「代表學者（年代）」若不確定，是否已誠實標「需查證」而非猜一個年代
- [ ] 「在跟誰對話」是否寫出具體的另一個理論名稱，而不是空泛的「其他理論」
- [ ] 「常見考法與陷阱」是否包含至少一個「容易答錯的地方」，不只是重述定義
- [ ] 「在地/實務連結」是否為具體的台灣或亞太案例，而非泛稱「企業實務」

## 間隔複習排程追蹤表（依遺忘曲線安排 1/3/7/14 天回訪）

| 理論名稱 | 考點層級 | 首見日期 | 第1次回訪(+1天) | 第2次回訪(+3天) | 第3次回訪(+7天) | 第4次回訪(+14天) | 目前信心度 |
|---|---|---|---|---|---|---|---|
| 〔　　〕 | 必考/常考/冷門 | 　 | ☐ 完成日:__ | ☐ 完成日:__ | ☐ 完成日:__ | ☐ 完成日:__ | 低/中/高 |
| 〔　　〕 | 　 | 　 | ☐ | ☐ | ☐ | ☐ | 　 |
| 〔　　〕 | 　 | 　 | ☐ | ☐ | ☐ | ☐ | 　 |

**使用方式**：
1. 每張新卡填完當天登錄「首見日期」。
2. 依考科範圍診斷（SKILL.md 階段一）判定的「必考」理論，優先排入複習排程；
   「冷門」理論可延後或降低回訪頻率（如只做首見＋7天兩次）。
3. 每次回訪用 Feynman 回講法自測：闔上卡片，用白話講給假想的外行人聽，
   講不清楚的地方＝還沒真懂，當次信心度標「低」，縮短下次回訪間隔（如
   從 7 天提前到 3 天再測一次）。
4. 信心度連續兩次回訪都是「高」，可考慮把該理論的複習頻率降到考前總複習
   才再看一次，把零碎時間讓給信心度「低/中」的理論。

## 跨科整合卡（選用，對應 SKILL.md 階段四）

當某理論常在跨科整合申論題出現時，額外填一張整合卡，記錄它與其他考科理論
的橋接論述，考前可直接拿出來複習整合破題句：

```
【整合橋樑：<理論A> × <理論B>】
橋接情境：<什麼類型的申論題會同時考這兩個理論>
橋接論述句（可直接默背的一句話）：<…>
常見出題方向：<如「用組織理論解釋創新採用」「用管理心理學解釋策略決策偏誤」>
```
