# 幻覺風險訊號判準表

> 對應 SKILL.md 階段三「幻覺風險訊號標記」。**每一項訊號都只能拿來標記
> 「可疑，需工具驗證」，不能單獟拿來宣稱某文獻是真或是假**——這條界線是
> 本 skill 存在的理由(無網環境無法連線資料庫確認)，任何時候都不能跨越。
> 真偽定論一律指路到有網路的 `check-citations`（Claude Code 環境需加
> `anthropic-skills:` 前綴）。

## 使用方式

逐筆參考文獻對照下表訊號，命中任一項就在稽核報告中標記「⚠ 疑似，需工具
驗證」並註明命中的具體訊號；命中多項訊號的文獻風險等級應標為 Major。
**沒有命中任何訊號不代表文獻一定真實存在**——只是離線看不出問題，仍建議
全部送 `check-citations` 做最終確認，尤其是投稿或論文定稿前。

## 訊號一：DOI 格式錯誤（可離線判定格式對錯，但格式對不等於文獻真實存在）

| 判準 | 可疑程度 |
|---|---|
| 不以 `10.` 開頭 | 高——真實 DOI 一律以 `10.` 開頭，格式錯誤幾乎確定是誤植或捏造 |
| 前綴後沒有 `/` 分隔的後綴部分(如只有 `10.1016`沒有斜線後內容) | 高 |
| DOI 內含空格、中文字元、或明顯非文獻識別碼的字串 | 高 |
| 前綴數字位數異常(真實出版社前綴通常為 4 位數字，如 10.1016、10.1177) | 中——需搭配其他訊號一起看，部分小型出版社前綴長度不同 |

**為何可疑**：DOI 是由 CrossRef 或其他 DOI 註冊機構分配的標準化識別碼，
格式有嚴格規範；格式錯誤代表這不是一個有效的 DOI 字串，很可能是 AI 生成
時模仿格式但沒有對應到真實註冊記錄。
**定論需要**：用 `check-citations` 查 CrossRef API，確認該 DOI 是否真實
註冊、指向的文獻是否與引用的作者/標題/年份相符。

## 訊號二：頁碼範圍異常

| 判準 | 可疑程度 |
|---|---|
| 起頁大於迄頁(如 385–210) | 高——邏輯上不可能，幾乎確定是誤植或捏造 |
| 頁碼範圍過長(單篇論文超過 100 頁，如 1–500) | 中——部分特刊或專書篇幅可能較長，需搭配期刊類型判斷 |
| 頁碼範圍過短(只有 1 頁，如 385–385)且非公認的短文/評論類型 | 低中——某些 letter/comment 類文章確實只有 1 頁，不能單獨定罪 |
| 頁碼與該期刊常見篇幅明顯不符(如某期刊慣例單篇 15–25 頁，此筆卻標 385–617) | 中——需要知道該期刊的一般篇幅慣例才能判斷，跨期刊比較時保守標記 |

**為何可疑**：頁碼範圍是期刊排版後的固定事實，AI 幻覺生成時容易在數字
細節上出現不合邏輯的組合(如複製了某篇文獻的起頁卻配上另一篇的迄頁)。
**定論需要**：用 `check-citations` 查 CrossRef／出版社網站核對實際頁碼。

## 訊號三：作者—年份—期刊組合可疑

| 判準 | 可疑程度 |
|---|---|
| 期刊創刊年晚於引用年份(該期刊當年尚未存在) | 高——若能查到該期刊的創刊年份，這是可離線判定的邏輯矛盾 |
| 年份晚於目前日期(引用「未來」發表的文獻) | 高——除非是「已接受、即將出刊」(in press)並有註明，否則邏輯矛盾 |
| 作者的已知研究領域與期刊主題明顯錯配(如純財務計量學者的論文出現在
  人資領域專門期刊，且無合著者背景可解釋) | 中——需要一定領域知識才能判斷，避免誤殺跨領域合作論文 |
| 知名學者「被引用」的論文主題與其學術生涯已知方向明顯不符 | 中——同樣需要背景知識佐證，單獨此項不足以斷定 |

**為何可疑**：AI 生成幻覺文獻時，經常正確地知道某學者是某領域的權威，
卻把其姓名配上一個該學者實際上未曾發表過的具體篇名或期刊。
**定論需要**：用 `check-citations` 查該作者在 Semantic Scholar / OpenAlex
的實際發表清單，確認是否真有此篇。

## 訊號四：標題過度泛化或與具體宣稱不符

| 判準 | 可疑程度 |
|---|---|
| 標題為「A Comprehensive Review/Survey of…」等泛化字眼，卻被引用來支持
  一個非常具體的實證數字或效果量 | 中——泛稱式標題本身不代表文獻造假，但常是 AI 生成的偏好句式 |
| 標題內容與該筆文獻被引用的上下文語意不符(如標題講定性研究，卻被引用
  作為量化效果量的來源) | 中高——這種語意錯配值得優先標記 |

**為何可疑**：這類標題句式是語言模型生成學術標題時的高頻樣態，本身
不是決定性證據，但搭配其他訊號一起看時能提高整體懷疑權重。
**定論需要**：用 `check-citations` 確認標題與作者的對應關係。

## 訊號五：Chimeric(拼接式)文獻疑慮

| 判準 | 可疑程度 |
|---|---|
| 標題聽起來高度真實、具體、符合領域慣例，但配上的作者組合顯得突兀
  (如知名學者A與從未合作過的學者B首次合著、且主題偏離兩人已知專長) | 中高 |
| 引用的文獻「聽起來」像是真實存在的某篇經典文獻的變體(標題相似度高但
  細節微調) | 中——可能是版本混淆(如把2006年那篇的標題誤植成2009年的期刊卷期)
  也可能是拼接，離線無法區分 |

**為何可疑**：Chimeric citation 是「真實標題＋錯誤作者」或「真實作者＋
虛構標題」的混合體，介於「完全真實」與「完全捏造」之間，是離線最難
判斷、也最容易被忽略的一類幻覺，因為表面上每個元素看起來都眼熟。
**定論需要**：**只能標「疑似chimeric」，離線無法確認**，必須用
`check-citations` 分別核對作者的實際發表清單與該標題的實際作者是否相符。

## 訊號組合的風險等級對照（供 SKILL.md 三級嚴重度標記時參考）

| 命中訊號組合 | 建議嚴重度 |
|---|---|
| 命中訊號一(DOI格式錯) 且 命中訊號三(作者-期刊錯配) | Fatal 或 Major(視錯配明顯程度) |
| 僅命中訊號二(頁碼異常)，其餘正常 | Minor 或 Major(視異常程度，起訖頁邏輯矛盾應為 Major) |
| 僅命中訊號四(標題泛化)，其餘正常 | Minor(單獨此訊號證據力最弱) |
| 命中訊號五(chimeric疑慮) | Major(即使只有此訊號，因chimeric一旦成真影響學術聲譽的後果嚴重) |
| 未命中任何訊號 | 不特別標記，但仍建議整份文獻清單送 check-citations 做最終確認 |

## 重申能力邊界

本表所有判準都只回答「離線看起來像不像有問題」，不回答「這篇文獻是否
真實存在」。兩者是不同層次的問題：格式錯誤是可以離線肯定的事實，真偽
存在與否需要連上文獻資料庫查證，這是離線環境的物理限制，不是嚴謹度
選擇的問題。
