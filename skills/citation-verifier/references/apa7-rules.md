# APA 7 常見文獻類型格式表

> 對應 SKILL.md 階段二「APA 7 格式診斷」。本表列出商管論文最常遇到的文獻
> 類型格式，逐筆比對時直接查對應列即可，不必整本 APA 7 手冊翻找。中文文獻
> 慣例列在最後一節。**本表只判斷格式是否合規，不判斷文獻是否真實存在**
> ——真偽判斷見 `references/hallucination-signals.md`，離線都無法定論真偽。

## 一、期刊論文(Journal Article)

**格式**：
```
作者姓, 名縮寫., & 作者姓, 名縮寫. (年份). 篇名句首大寫(sentence case),其餘
小寫，除專有名詞外. 期刊名全大寫每字首字母大寫(Title Case)，斜體, 卷(期)，
起頁–迄頁. https://doi.org/10.xxxx/xxxxx
```

**檢查點**：
- 篇名用 sentence case（只有句首與冒號後首字大寫，專有名詞除外）；
  期刊名用 Title Case（每個實詞首字母大寫）——這兩者大小寫規則相反，
  是最常見的格式錯誤。
- 期刊名與卷號(volume)應為斜體；期(issue)號不斜體，用括號包住緊接卷號
  之後，如 `80(2)`。
- DOI 一律用 `https://doi.org/10.xxxx/xxxxx` 格式呈現，不用 `doi:` 前綴
  （APA 6 用 `doi:`，APA 7 已改為完整 URL 形式）。
- 無 DOI 時不需捏造或省略成 `doi: N/A`，直接不放此欄即可；若文獻有穩定
  URL(如僅線上發表)可放該 URL。

**範例**：
```
Villalonga, B., & Amit, R. (2006). How do family ownership, control, and
management affect firm value? Journal of Financial Economics, 80(2),
385–417. https://doi.org/10.1016/j.jfineco.2004.12.005
```

## 二、書籍(Book)

**格式**：
```
作者姓, 名縮寫. (年份). 書名句首大寫，斜體(第N版，若非第一版). 出版社.
```

**檢查點**：
- 書名斜體，句首大寫規則同期刊論文篇名(sentence case)。
- APA 7 起，出版地(城市)不再需要列出，只列出版社名稱。
- 版次資訊(如有)放在書名後的括號內，不斜體：`(2nd ed.)`。
- 電子書若有 DOI 比照期刊論文格式加在最後；無 DOI 的一般紙本書不需加 URL。

**範例**：
```
Williamson, O. E. (1985). The economic institutions of capitalism: Firms,
markets, relational contracting. Free Press.
```

## 三、書籍專章(Book Chapter)

**格式**：
```
作者姓, 名縮寫. (年份). 專章篇名句首大寫. 於 編者名縮寫. 編者姓 (主編),
書名句首大寫，斜體 (頁碼範圍). 出版社.
```

**檢查點**：
- 專章篇名不斜體；書名斜體——與期刊論文格式相反的地方要注意（期刊論文是
  篇名不斜體、期刊名斜體，書籍專章是專章不斜體、書名斜體，規則一致但常
  被誤套用成篇名斜體）。
- 編者姓名後方加 `(主編)` 或英文 `(Ed.)` / `(Eds.)`(多位編者)。
- 頁碼範圍放在書名後的括號內：`(pp. 123–145)`。

**範例**：
```
Eisenhardt, K. M. (1989). Agency theory: An assessment and review. In L. L.
Cummings & B. M. Staw (Eds.), Research in organizational behavior (Vol. 11,
pp. 39–74). JAI Press.
```

## 四、研討會論文(Conference Paper)

**格式（正式出版於論文集）**：
```
作者姓, 名縮寫. (年份, 月). 篇名句首大寫 [論文發表形式，如 Paper presentation
或 Poster session]. 研討會全名, 舉辦城市, 國家.
```

**檢查點**：
- 若研討會論文有正式出版的論文集頁碼或 DOI，優先比照期刊論文格式引用；
  未正式出版的口頭發表才用上述會議引用格式。
- 方括號內註明發表形式(論文發表/海報發表)，這是研討會引用格式的特徵，
  常被忽略。

## 五、網路資料(Webpage / Online Report)

**格式**：
```
作者(個人或機構). (年份, 月 日，或 n.d.若無日期). 網頁標題句首大寫，斜體
(若為獨立報告類). 網站名稱(若與作者不同才需要). URL
```

**檢查點**：
- 無明確作者時，機構名稱視為作者(如政府機關、公司名稱)。
- 無日期時標記 `(n.d.)`，不得自行假設或捏造日期。
- 網頁若可能更新內容，建議加註「取用日期」(retrieved date)於 URL 前，
  APA 7 一般不強制要求，但內容易變動的網頁(如維基百科)建議加註。

## 六、政府/機構報告(Report)

**格式**：
```
機構名稱. (年份). 報告標題句首大寫，斜體 (報告編號，若有). 出版單位(若與
作者不同). URL(若為線上取得)
```

**檢查點**：
- 機構全名優先於縮寫(可在首次引用時註明縮寫供後續內文使用，如
  「國家科學及技術委員會(國科會，NSTC)」)。
- 報告編號放在標題後括號內，不斜體。

## 七、內文引用格式重點

- **首次引用**：3 位以上作者，第一次出現即可用「第一作者 et al., 年份」
  （APA 7 相較 APA 6 簡化了這條規則，不需要在首次列出全部作者）。
- **& 用法**：括號內引用多位作者用 `&`（如 `(Smith & Jones, 2020)`）；
  文字敘述中用 `and`（如 `Smith and Jones (2020) found that…`）。
- **同作者同年多篇**：依標題字母順序加 a/b/c 區分，如 `(Chen, 2023a, 2023b)`，
  參考文獻清單中也要對應標註且排序一致。
- **中文姓名作者**：內文引用一般沿用原文姓氏（如中文期刊本身用全名，
  英文引用中文作者建議依原文文獻的拉丁拼音或期刊自訂格式，兩篇引用同一
  作者要確認拼音一致，避免被誤判為兩位不同作者）。

## 八、參考文獻清單排序與作者列表規則

- 依第一作者姓氏字母順序排列；同姓氏比對第二作者。
- 7 位以上作者：列出前 6 位，插入刪節號 `…`，再列最後 1 位作者(APA 7
  規則，與 APA 6 的「列前 7 位加 et al.」不同，是常見的新舊版本混淆點)。
- 機構作者(無個人作者)：直接以機構全名作為作者欄。

## 九、中文文獻慣例(台灣學術界通行做法，非 APA 7 官方規則但普遍採用)

- 中文期刊論文格式比照期刊論文規則，但篇名與期刊名之間通常不強制英文
  sentence/title case 的大小寫區分(中文無大小寫)，重點在標點符號使用全形
  或半形需前後一致。
- 中文作者姓名內文引用：直接使用全名（不縮寫名字），如「陳明哲（2020）」，
  與英文姓氏+縮寫名的格式不同，兩者不要混用同一套規則互相套用。
- 中英文文獻混合的參考文獻清單，慣例上依語言分兩區塊排列（中文文獻依
  姓氏筆畫或注音排序在前，英文文獻依字母順序排列在後），但部分期刊要求
  全部依字母/羅馬拼音統一排序——**格式以投稿期刊之作者須知為準**，本表
  僅列學界普遍慣例，不代表所有期刊的強制規定。
- 翻譯著作或譯本：作者列原作者，譯者於書名後以 `(譯)` 標註，並列原文
  出版年於書名後括號，如「(原著出版年：1985)」。
